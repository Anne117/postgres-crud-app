# Задание №4 — моделирование угроз (STRIDE + DREAD) для приложения из задания №3

Объект моделирования — CRUD-приложение к PostgreSQL «склад интернет-магазина»
(`postgres-crud-app`, задание №3). Методология — **STRIDE**, инструмент —
**OWASP Threat Dragon** (формат файла модели v2), оценка рисков — **DREAD**.

## Артефакты

| Файл | Назначение |
|------|------------|
| `report/hw4-otchet.docx` | **Отчёт**: описание объекта, методика, DFD, локализованные угрозы STRIDE, таблицы расчёта DREAD, итоговая таблица угроз по убыванию риска, сопоставление топ-5 с УБИ БДУ ФСТЭК, приложения А/Б/В |
| `model/dfd-crud-app.drawio` | Исходная диаграмма потоков данных (draw.io / diagrams.net) |
| `model/threat-dragon-crud-app.json` | Исходный файл модели OWASP Threat Dragon v2 — диаграмма + локализованные угрозы STRIDE на элементах |
| `model/dfd-crud-app.svg`, `model/dfd-crud-app.png` | Экспорт диаграммы (PNG использован в отчёте) |
| `model/report-data.json` | Машиночитаемые данные отчёта (элементы, потоки, угрозы, DREAD, УБИ) |
| `catalog.py` | Единый источник истины: элементы DFD, локализованные угрозы STRIDE, оценки DREAD, соответствие УБИ |
| `tools/make_model.py` | Генератор `.drawio`, Threat Dragon JSON, PNG/SVG, `report-data.json` |
| `tools/make_report.py` | Сборка отчёта `.docx` |
| `tools/bdu.py`, `tools/ubi_index.json`, `tools/ubi_details.json` | Извлечение и индекс УБИ с bdu.fstec.ru |

## Состав диаграммы

* 2 внешние сущности (actor): `ext_user` (пользователь), `attacker` (нарушитель);
* 6 процессов (process): `p_app`, `p_sqlsafe`, `p_db`, `p_log`, `p_pg`, `p_docker`;
* 4 хранилища (store): `ds_creds`, `ds_conf`, `ds_log`, `ds_db`;
* 18 потоков данных;
* 4 границы доверия: `tb_host` (хост/Docker daemon) ⊃ `tb_app` (контейнер приложения),
  `tb_db` (контейнер СУБД), `tb_ws` (рабочая станция: пользователь и нарушитель).

Потоки от нарушителя рисуются красным пунктиром как пересекающие границы доверия.

## Результаты

15 локализованных угроз STRIDE. Топ-5 по DREAD:

| # | ID | Угроза | Риск | УБИ БДУ ФСТЭК |
|---|----|--------|------|---------------|
| 1 | T-04 | SQL-инъекция через значения фильтров и INSERT/UPDATE | 20 | УБИ.006 «Угроза внедрения кода или данных» |
| 2 | T-05 | Несанкционированная модификация данных напрямую в СУБД | 20 | УБИ.033 «Угроза использования слабостей кодирования входных данных» |
| 3 | T-15 | Использование административной роли `app_admin` | 20 | УБИ.122 «Угроза повышения привилегий» |
| 4 | T-06 | Подмена конфигурационного файла `app.docker.conf` | 19 | УБИ.033 «Угроза использования слабостей кодирования входных данных» |
| 5 | T-03 | Доступ к учётным данным в env-файле `crud.env` | 18 | УБИ.030 «Угроза использования информации идентификации/аутентификации, заданной по умолчанию» |

Соответствие всех 15 угроз — в приложении Б отчёта.

## Воспроизведение

```bash
cd hw4
python tools/make_model.py     # drawio + Threat Dragon JSON + PNG/SVG + report-data.json
python tools/make_report.py    # report/hw4-otchet.docx
```

Требуется `python-docx` (`pip install python-docx`) и draw.io CLI для экспорта
PNG/SVG (`C:\Program Files\draw.io\drawio.exe`).
